## 本轮修复/发现

| 项 | 说明 |
|---|---|
| 首屏 401 闪烁（已修，commit `0e3b6f5`） | `HistoryPanel` 挂载即请求，而 token 由 `useEffect` 恢复，首帧为空 → 先吃 401。加 `tokenReady` 闸门后复验无 401 |
| secret 生效窗口期（非缺陷） | 切换 `MAGPIE_BASE_URL` 后立即生成会拿到一次旧域名失败；等 20–30s 重试成功。已写入 `tools/README-tunnel.md` 加粗警告 |
| 断言写错（非产品缺陷） | 首次 T8 判「无标签」是因为用了 `/#\w+/`，JS 的 `\w` 不含中日韩字符 → 中文标签匹配不到。改用直接读取详情文本后确认标签齐全 |

## 剪贴板说明

`navigator.clipboard.readText()` 在无焦点窗口会 15s 超时（浏览器要求 focus + 权限），
故**剪贴板写入内容**未做端到端断言；但：
- 按钮反馈链路已验（T11 四个按钮全过）
- 写入 payload 的正确性由单测覆盖（`note.renderNoteText`：含标题+正文+标签、按 titleIndex 切换）
