# 计费与配额

## 1. 计费方式

模型调用按 token 计费，输入与输出分别计价，具体单价见控制台价格页。向量检索按查询维度计费，存储按存储维度计费。

## 2. 免费额度

免费额度每月一号重置，不累积。免费额度用尽后，服务会返回明确的额度提示，而不是笼统的服务不可用。若当日额度耗尽，通常次日恢复。

## 3. 成本控制建议

三个有效的降本手段：一是压缩输入长度（去掉无关上下文）；二是减少重复调用（同样的请求做缓存）；三是对批量任务使用更便宜的模型做预筛，只把少量样本交给强模型。

## 4. 预算告警

预算达到月度额度的百分之八十时触发告警邮件，达到百分之百时停止调用非关键任务，关键任务仍可继续但会记录审计日志。
