# 权限与安全

## 1. 访问控制

服务通过访问令牌控制访问。配置令牌后，所有接口请求必须携带令牌，缺失或错误统一返回未授权状态码，不区分「没带」和「带错」，避免给攻击者提供信息。

## 2. 密钥管理

模型凭据只存放在服务端环境变量中，不进入前端产物，不进入代码仓库。审计时会扫描构建产物中是否出现明文密钥，出现即判定为缺陷。

## 3. 外部链接安全

允许用户提交外部链接抓取内容，因此必须防范服务端请求伪造：只允许 http 与 https 协议，禁止内网地址、回环地址与云元数据地址，域名解析后要再次校验解析结果，重定向要手动逐跳校验。

## 4. 数据留存

问答历史保存在数据库中，包含问题、回答与引用的文档。删除文档时，其分片与向量索引必须一并清理，否则检索会出现指向空内容的引用。
